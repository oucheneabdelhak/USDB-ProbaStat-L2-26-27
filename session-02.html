Chapter 1 · Session 2
Quantitative characters and grouped data

Discrete and continuous variables, classes, histograms, polygons and cumulative curves

Today you will be able to:
  • distinguish a discrete from a continuous quantitative character;
  • group continuous data into classes, and choose the number of classes;
  • read and build a histogram, a polygon of frequencies and a cumulative frequency curve.

Session 1 counted qualitative modalities. Today, the same counting applies — but on the real line.

1Two kinds of quantitative character

Discrete quantitative
Values are isolated, generally integers: the number of distinct values is finite and small.

Number of GPUs per node (1, 2, 4, 8, 16), commits per day, failed login attempts.

Continuous quantitative
Values fill an interval: in principle infinitely many, rarely repeated because the measurement has finite precision.

Latency (ms), dataset size (GB), energy (MWh), detection time (h).

What changes from Session 1
Counting is exactly the same: \(n_i\), \(f_i=n_i/n\), \(p_i=100f_i\), sums to \(n\), \(1\) and \(100\). What changes is the shape of the table:
  • Discrete — one row per observed value;
  • Continuous — one row per class (an interval), because a table with one row per value would have as many rows as the sample has individuals.
Why grouping loses information
Two datasets with the same class counts may have different means and different variances. What is gained is legibility and robustness to isolated extremes; what is lost is the exact position of each observation inside its class.

2Classes, centres and amplitudes

Definition
A class is an interval \([a_i,b_i[\) into which the values of a continuous character are grouped. Its centre and its amplitude are \[ x_i \;=\; \frac{a_i+b_i}{2}, \qquad a \;=\; b_i - a_i . \]
Example
For the class \([50;60[\): \[ x_i = \frac{50+60}{2} = 55\ \text{ms}, \qquad a = 60 - 50 = 10\ \text{ms}. \]
Two rules for the classes
  1. The classes must be disjoint: \( [a_i,b_i[ \cap [a_j,b_j[ = \varnothing \) for \(i\neq j\).
  2. Their union must contain every observation: \( \bigcup_i [a_i,b_i[ \supseteq \{x_1,\dots,x_n\} \).
Remark — discretisation
From now on, an observation in \([a_i,b_i[\) will be treated as if it were worth its class centre \(x_i\). This is the same move as replacing an object by its centre of gravity: it allows the formulas of the discrete case to apply unchanged. The approximation is negligible when the classes are narrow and equal.

3How many classes?

Rule of thumb
For a sample of size \(n\) and a range \(r = x_{\max}-x_{\min}\): \[ K \;=\; \begin{cases} \sqrt{n} & \text{if } n<50,\\[4pt] 1+\dfrac{10}{3}\log_{10}(n) & \text{if } n\ge 50, \end{cases} \qquad a = \frac{r}{K}. \] It is recommended to choose an odd number of classes and a round amplitude \(a\).
Example — inference latency, n = 100
\(r = 80-30 = 50\) ms. The rule gives \(K = 1 + \tfrac{10}{3}\log_{10}(100) = 7.67\). We round to K = 5 with amplitude \(a = 50/5 = 10\) ms: a clean value in the unit of the data.

5Cumulative frequencies

Definition
The increasing cumulative absolute frequency of class \(i\) is \[ n_i^{\nearrow} \;=\; n_1 + n_2 + \dots + n_i , \] the number of observations whose value is \(\le\) the upper bound of class \(i\).
Properties
  • \(n_1^{\nearrow} = n_1\) and \(n_K^{\nearrow} = n\) — the curve starts at the first frequency and ends at the sample size;
  • The sequence \((n_i^{\nearrow})\) is non-decreasing;
  • The corresponding relative cumulative is \(f_i^{\nearrow} = n_i^{\nearrow}/n\), and \(f_K^{\nearrow}=1\).

6Bar chart for a discrete quantitative variable

Definition
Each value \(x_i\) is a vertical rectangle of height proportional to \(n_i\). Unlike the qualitative case, the values are placed on the axis in their natural numerical order — the spacing between bars carries information.

7Polygon of frequencies

Definition
The polygon of frequencies of a discrete quantitative variable joins the points \((x_i,n_i)\), extended by \((x_1-a,0)\) and \((x_k+a,0)\) where \(a\) is the common spacing of the values (or a visual padding when the values are not equally spaced).

Same data as the previous slide. The profile shows at once that the distribution is concentrated on small values, with a long right tail.

When to use it
The polygon is preferred to the bar chart when the variable is quantitative and the number of distinct values is large: a broken line shows the profile, the mode and the asymmetry, whereas a forest of bars hides them. For a qualitative character the polygon is meaningless — the order of the modalities is arbitrary.

8Histogram — the area counts, not the height

Definition
The histogram of a continuous variable in classes is a set of rectangles with base = class interval and height \[ h_i = n_i\ \text{when all classes have the same amplitude,} \qquad h_i = \frac{n_i}{a_i}\ \text{when amplitudes differ.} \] In all cases, the area of a rectangle is proportional to the number of observations.
The pitfall. Below is the same data with one wider class: \([30;40[,[40;50[,[50;60[,[60;80[\). Same counts \(8,22,41,29\). Two histograms:

❌ Heights = \(n_i\) — the wide class looks twice as important as it is.

✓ Heights = \(n_i/a_i\) — the area is proportional to the count.

Histogram ≠ bar chart
In a bar chart, only the height counts; the width is arbitrary. In a histogram, the area counts; the width is the amplitude of a class. Drawing a histogram with unequal classes and heights equal to the counts is a mistake, not a stylistic choice.

9Cumulative frequency curve

Definition
The cumulative frequency curve plots the increasing cumulative frequency \(n_i^{\nearrow}\) against the upper bound of each class and joins the points by segments. It is non-decreasing, starts at \(0\) and ends at \(n\).

What this curve is for
It answers “how many observations are below a threshold?” and “below which threshold do half the observations lie?”. It is the graphical counterpart of the cumulative frequencies and the object that will become a distribution function in Chapter 3.

✓Summary of Session 2

  • A quantitative character is discrete (isolated values) or continuous (any value in an interval).
  • Continuous data are grouped into classes \([a_i,b_i[\), with centre \(x_i=(a_i+b_i)/2\) and amplitude \(a=b_i-a_i\).
  • Choice of K: \(K=\sqrt{n}\) if \(n<50\); \(K=1+\tfrac{10}{3}\log_{10}n\) if \(n\ge 50\); amplitude \(a=r/K\), rounded to a convenient value.
  • Cumulative frequencies: \(n_i^{\nearrow}=n_1+\dots+n_i\), from \(n_1\) to \(n\).
  • Histogram: area is proportional to count. With equal amplitudes, height \(=n_i\); with unequal amplitudes, height \(=n_i/a_i\).
  • Polygon and cumulative curve are profile views of the same data, used for shape and for percentiles.
Common mistakes
  • Drawing a histogram with unequal class widths and heights equal to the counts.
  • Confusing a bar chart (width arbitrary) with a histogram (width = class amplitude).
  • Choosing the classes after looking at the data to make one class stand out.
  • Reading the median from the counts instead of from the cumulative column.
  • Using the polygon or cumulative curve for a qualitative character.
